Build a web app using React.js (Tailwind) and FastAPI. Connect to Spotify API via OAuth. Implement, in increasing order of complexity:
1. User login with Spotify OAuth.
2. Fetch liked/recent songs.
3. UI for viewing/editing playlists/queues.
4. Save, name, and replay queues as playlists.
5. (Optional) Use OpenAI for playlist naming.
6. Auto-refresh genre playlists.
7. On liking a song, auto-add to genre playlist or create new playlist.

Keep builds clean and iterate feature-by-feature.
Each PR/commit should address a single feature before advancing.
